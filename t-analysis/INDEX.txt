MAIN SCRIPTS (Executable)
════════════════════════════════════════════════════════════════════

✓ run-bundle-scripts.sh
  - Main script that executes analysis scripts from bundles
  - Discovers scripts in var/log/scripts/ of each bundle
  - Runs base analysis scripts from scripts/ directory
  - Generates per-bundle analysis reports
  - Usage: bash run-bundle-scripts.sh <TICKET_ID>

✓ generate-bundle-analysis-report.sh
  - Creates beautiful HTML report from analysis results
  - Generates interactive web-based report with statistics
  - Includes table of contents and bundle navigation
  - Usage: bash generate-bundle-analysis-report.sh <TICKET_ID>

✓ analyze-complete-bundle.sh
  - Master orchestration script for complete workflow
  - Runs all steps in sequence: extract → analyze → report
  - Generates workflow logs and summary
  - Usage: bash analyze-complete-bundle.sh <TICKET_ID>

✓ extract-bundle-errors.sh
  - Utility script for extracting errors from bundles
  - Part of the workflow, called by analyze-complete-bundle.sh
  - Can also be run standalone for error extraction only

WORKFLOW OVERVIEW
════════════════════════════════════════════════════════════════════

STEP 1: Extract (Optional)
  Source: Support bundle files
  Output: Extracted bundle directories

  Source: var/log/scripts/ in each bundle + base scripts/

  Output: bundle_script_analysis/ with results

  Output: comprehensive_bundle_analysis.html

FEATURE SUMMARY
════════════════════════════════════════════════════════════════════

✅ Automatic Script Discovery
   - Finds scripts in bundle directories automatically
   - Executes both embedded and base analysis scripts

✅ Context Passing
   - Scripts receive environment variables:
     * $VAR_LOG - Path to bundle's var/log
     * $BUNDLE_DIR - Path to bundle
     * $BUNDLE_NAME - Name of bundle

✅ Comprehensive Reporting
   - Per-bundle analysis summaries
   - Overall statistics and metrics
   - Interactive HTML dashboard
   - Complete workflow logs

✅ Extensible
   - Add custom analysis scripts to scripts/ directory
   - Automatically executed with bundle context
   - Results included in reports

✅ Error Tolerant
   - Continues on script failures
   - Logs all errors for review
   - No destructive operations
